Sort Coco

8 ways to sort. Same C-Block 8x8 base, different sorting animations. Each one maps to a real Trust Center action.

Sorting Variations
01
Left / Right
Approved vs Flagged

Eyes flick left → green flash (approved). Eyes flick right → gold flash (needs review). The classic triage sort.

Approved Flagged
02
Pass / Reject
Check vs X

A green checkmark flashes, then a red X. Binary decision — does this doc meet the bar or not? Steady, confident eyes.

Check Reject
03
Priority Stack
High → Med → Low

Items drop through three levels — red (urgent) at top, gold (medium) in middle, green (low) at bottom. Eyes track downward with each item.

Urgent Medium Low
04
Belt Through
In White → Out Green

A doc enters the C opening as white (unprocessed), passes through the curve, and exits green (processed). The C IS the sorting machine.

Unprocessed Processed
05
Queue Sort
First In, First Out

Items stack up on the left as a queue. One at a time gets pulled across and dispatched right. Orderly, methodical. The backlog processor.

Queued Processing Dispatched
06
Tag Sort
Label & Categorize

A doc appears blank, then gets tagged — green (SOC2), gold (ISO), etc. Eyes blink between each tagging. Categorizing trust docs by framework.

SOC2 ISO Categorize
07
Route Sort
Send to Person

Doc arrives from above. Eyes think. Then it gets routed diagonally to the right person. Gap routing — sending questions to the right admin.

Routing Smart Assign
08
Batch Sort
All at Once

A cluster of unsorted docs (white) all flash green simultaneously. Bulk processing — Coco handles the whole questionnaire in one go.

Bulk Instant Efficient

All 8 use the same C-Block 8x8 base. Each sorting style maps to a real Trust Center action — triaging docs, pass/reject decisions, priority levels, belt processing, queue management, framework tagging, gap routing, and bulk questionnaire handling.
