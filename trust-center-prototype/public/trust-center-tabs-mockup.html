Top Knowledge Base FAQs
Access Management How does Arcline manage user access controls? ▾
We implement role-based access control (RBAC) with least-privilege principles. All access is reviewed quarterly and requires manager approval.
Application Security What is your secure development lifecycle? ▾
We follow OWASP guidelines with mandatory code reviews, SAST/DAST scanning, and penetration testing before each release.
Data Privacy Where is customer data stored and processed? ▾
Customer data is stored in US-based AWS regions with encryption at rest (AES-256) and in transit (TLS 1.3).
Infrastructure How is your infrastructure secured? ▾
We use VPCs with strict security groups, WAF protection, DDoS mitigation, and continuous monitoring via Datadog.
Incident Response What is your incident response process? ▾
We maintain a dedicated IR team with 24/7 on-call rotation. Customers are notified within 72 hours of any breach affecting their data.
