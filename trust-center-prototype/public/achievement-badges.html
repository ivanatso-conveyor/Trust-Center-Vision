Design Reference

Conveyor Green Palette

Shared Traits

  • 8×8 pixel grid, image-rendering: pixelated
  • SVG <rect> elements only (no paths)
  • Subtle <animate> for liveliness
  • Monochrome green — same palette as Coco
  • Scales crisp from 16px to 64px+

Animation Notes

  • All durations 1.2s–3.5s (no fast flashing)
  • Uses fill or opacity animations only
  • Small icons (16px) omit animations for clarity
  • Each badge has a unique signature animation
